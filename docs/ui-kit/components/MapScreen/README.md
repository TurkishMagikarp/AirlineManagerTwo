# MapScreen

The Karte screen assembled at 1280 × 760: the map with its floating controls and a selected airport, and the routes in view below. A reference composition, not a component.

- The map takes the full width under the ClockBar. Layers top left, zoom top right, scale bottom left, the selected object's card on the right.
- The table below lists the routes in view; selecting a row selects the route on the map and the other way round.
- Nothing floats over the base marker of the selected object.
