# RouteCard

Details of the route selected on the map or in a table. The consumer provides both ICAO codes, the city names, a status, the current leg and up to six facts.

- Title is the ICAO pair with an en dash; city names below.
- If an aircraft is on the route, a route leg shows where it is.
- The daily result is `go` or `stop` with an explicit sign.
- One action, which opens the schedule.

Godot: same container as AirportCard.
