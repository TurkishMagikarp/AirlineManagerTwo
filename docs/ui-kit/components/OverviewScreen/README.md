# OverviewScreen

The kit assembled as the Übersicht screen at 1280 × 760, to judge the parts together. It is a reference composition, not a component.

- NavRail left at 208px, ClockBar across the top, both outside the scrolling content.
- Content margin `space-5`, gap between sections `space-4`.
- Reading order: AttentionList, then MetricCards, then the fleet register beside running operations. Register and operations come before any purchase or planning form.
