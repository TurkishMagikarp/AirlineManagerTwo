# Checkbox

Selects any number of independent options: map layers, table filters. The consumer provides the label and the state.

- Box 18px, `radius-sm`, `surface-sunken` well; checked is an `accent` fill with an `on-accent` tick.
- The label is clickable and is a noun phrase, not a question.
- On the map, a checkbox may carry a swatch that repeats the mark it controls.

Godot: `CheckBox` with themed `checked` and `unchecked` icons.
