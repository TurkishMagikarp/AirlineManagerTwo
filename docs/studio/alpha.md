# Alpha plan

Owner's goal (2026-11-20): reach a playable alpha of the game. The Studio Lead decides the way there, may define new features and rules, and keeps the vision in `docs/game-design/00-vision.md` alive in everything it adds.

The Studio Lead owns this file. Developer changes it only as an issue asks.

## Exit criteria

- [ ] **Start and found.** From a fresh local profile, I can launch the desktop game offline, name an airline, pick a country and matching real airport, accept or change the displayed starting conditions, and reach Overview with the chosen company, base, starting cash and paused Day 1. I can correct invalid input in place. I can start a second company and still load the first company's named save.
  - [x] If I already have an airline open, New Game tells me which airline I am replacing and warns about unsaved progress. I can cancel and return to my current airline, or confirm and found the new company with my named saves still loadable.
  - [x] When I cancel the New Game form, I return to the same company screen with my route or aircraft selection and keyboard focus restored.
- [x] **Put the first route into service.** From the default start, I can acquire an affordable passenger aircraft, hire qualified staff through Staff, choose an airport pair within range, set a fare, and activate a feasible recurring schedule through the game UI. Routes opens with my airline's home airport, lets me choose the destination, and brings the new route's editor into view after creation. I can open Staff from a crew-blocked schedule, return to the same route with my entered values, and correct an invalid interval where I entered it. The corrected plan flies an outbound and a return leg.
  - [x] When I choose an aircraft in Routes, I can see which destinations are within its reference range. If none are in range, the planner explains how to proceed.
  - [x] When I have no aircraft, or my selected aircraft can reach no catalogue destination from my chosen origin, I can open Fleet Procurement directly from Routes and return to the same origin and destination with the aircraft list updated.
  - [x] If my chosen aircraft is parked at a different airport, Routes tells me where it is and lets me review and confirm a ferry to the route's origin. After landing and ground time, I can create the route from the same draft.
  - [x] If my ferry from Routes is blocked by missing rated pilots, I can open Staff with the required hire ready for review, hire explicitly, and return to the same draft or aircraft assignment to dispatch the ferry.
  - [x] If a ferry from Fleet is blocked by missing rated pilots, I can open Staff to review and hire the required pilots, then return to the same aircraft and destination to confirm the ferry.
  - [x] If my aircraft cannot ferry to the selected airport, Fleet and Routes explain the destination problem before offering pilot hiring. I can change my plan and see the relevant action for a reachable leg.
- [ ] **Understand the results and make a change.** In Routes I can see the upcoming departure or expected landing and then see passengers and financial results for completed flights. In Finances I can follow flight revenue and the costs charged to the company, and reconcile a test flight's contribution with the recorded totals. I can change the fare or capacity, advance to future flights, and inspect the updated results. For a completed flight that carried passengers and belly cargo, I can see ticket, cargo and ancillary receipts add up to total revenue and subtract flight costs to get the same result in Routes and Finances.
  - [x] In Overview and Finances I can see the same cumulative company revenue, costs and result, and reconcile them using ticket, cargo, ancillary and charter receipts and any charter penalty.
  - [x] I can see charter fees and penalties in the company charts for the periods when they are booked, and reconcile the recorded chart periods with company totals for a game played from founding.
- [ ] **Handle an operational interruption.** I can see why a planned flight is delayed or why its aircraft is unavailable. When a check is due, I can identify the aircraft, arrange maintenance, see its cost and duration, and verify that the aircraft stays grounded during the check and can resume service after it clears. An attention-driven time-jump stop tells me what needs attention and lets me continue after I deal with it. If an aircraft reaches its wear limit during a time jump, I stop at the grounding and can open the affected aircraft’s Fleet maintenance details from Attention.
  - [x] If a check is waiting for technicians, Attention opens the affected aircraft’s Fleet details, where I can see the staffing blocker and open technician hiring. Once the check is staffed, I can see when the aircraft will be released.
  - [x] If an active route loses crew, I can open Staff from Attention, see which qualified crew is missing, hire the replacements, and verify that the existing route resumes.
  - [x] In Routes I can see when an active aircraft’s next departure is blocked by missing qualified crew. A flight already airborne keeps its expected landing, and the same schedule shows a real departure again after I hire the missing crew.
  - [x] In Routes and Overview I can tell when my route aircraft is waiting for technicians. Once work begins, I see the same release time as in Fleet.
  - [x] When I book maintenance for an aircraft in flight, Routes and Overview keep its expected landing and tell me that maintenance follows. Routes shows a next departure again when I cancel the check or the aircraft is back in service with a departure ready to dispatch.
  - [x] When a time jump stops for a current Attention item, I can use the clock bar to open the relevant screen and entity directly, even with Attention collapsed. Once the item clears, its shortcut disappears.
- [ ] **Run and change the airline over two years.** In a viable passenger-airline run, using pause, speed and time jumps through the UI, I can reach the start of Year 3 (730 elapsed in-game days) with flights still operating and recorded financial activity from both years. I can add or reassign an aircraft and open, change or close a route during the run, then see the resulting schedule and finances. At the end I can keep playing the same company.
  - [x] I can wind down a flying route, see pending aircraft releases, and delete the route after they complete while retaining the route’s completed results in Finances.
  - [x] When I add an aircraft to an existing route, I can see if it is parked elsewhere, confirm a ferry to the route origin, and add it from the same selection after landing and ground time.
  - [x] After stopping a route while its assigned aircraft is parked at either endpoint, I can change the interval and restart the same route from that airport. The completed results stay with the route.
- [ ] **Save, quit and resume.** During that run I can create two named manual saves at different times, close the game, and reopen either save offline with the expected company, clock, cash, fleet and pending flight or commitment. Time spent with the game closed does not advance the clock. The restored event completes once after I resume. If I enable autosave, its entry is separately loadable and leaves my manual slots intact. While Save or Load is open, my company clock stays still. Closing the dialog continues from the held time, and loading uses the chosen save's clock settings.
  - [x] If I already have an airline open, loading a save tells me which game will replace it and lets me cancel without losing my current progress.
  - [x] If an airline is open, closing the window names my airline and warns about unsaved progress. I can cancel from the same moment, save, and quit when ready.
  - [x] I can distinguish same-named saves and tell which airline a manual save, autosave or backup will open before replacing my current company. Older saves without airline metadata are labeled accordingly and still load.
- [x] **Resolve financial distress.** In a separate distressed run or reproducible save, I can see why restrictions apply, the restructuring deadline, and an available rescue action when eligible. Recovery restores permitted operations. If I miss the deadline while still in distress and the company becomes insolvent, the final state explains that company management has ended and gives me a working path to Load or New Game. The persistent end-of-company notice stays visible on every company screen with Start, speed and jump controls unavailable; the frozen company stays inspectable and saveable, and New Game starts a separate world only after valid founding, leaving the ended company's named save loadable.
  - [x] If a time jump stops because my airline enters financial distress or restructuring, I can open the financing controls from the clock bar, read what changed and see the restructuring deadline and any available financing action.
- [ ] **Use the core screens end to end.** I can complete the founding, fleet, staff, routes, time, finance and save/load flows with visible keyboard focus and reachable actions at the supported minimum window size. Overview, Fleet, Routes, Map, Staff and Finances expose working views of the company. Empty and blocked states on these paths say what is missing or what I can do next. No required action leads to a placeholder screen or dead end.
  - [x] At the minimum window size, I can browse a full save list with the keyboard, see which save or action has focus, and cancel a load confirmation without losing my place.
